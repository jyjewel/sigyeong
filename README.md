# 詩畫 — 한시의 풍경 (프로토타입 v0.2)

한시를 한 구절씩 3지선다로 풀면서 픽셀아트 풍경을 한 층씩 쌓아 가는 웹 게임입니다.
『唐詩三百首』 수록작 17편이 들어 있습니다.

- 杜甫: 登高, 春望, 旅夜書懷
- 李白: 靜夜思, 黃鶴樓送孟浩然之廣陵, 下江陵
- 王維: 鹿柴, 山居秋暝, 竹里館
- 孟浩然: 春曉, 宿建德江
- 王之渙: 登鸛雀樓 / 張繼: 楓橋夜泊 / 韋應物: 滁州西澗
- 柳宗元: 江雪 / 劉禹錫: 烏衣巷 / 杜牧: 泊秦淮
React + TypeScript + Vite, HTML Canvas 2D로 만들었고 외부 이미지나 유료 API는 쓰지 않습니다.

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev          # 개발 서버 → 브라우저에서 http://localhost:5173
npm run build        # dist/ 에 정적 배포용 빌드
npm run build:single # dist-single/index.html 파일 하나로 실행되는 빌드
npm run preview      # 빌드 결과 미리보기
```

`dist-single/index.html`은 서버 없이 더블클릭으로도 열립니다.
주소 끝에 `#sprites`를 붙이면 모든 보기의 미리보기를 한 화면에 모아 보여 주는 개발용 스프라이트 시트가 열립니다. `#finale-chunwang`처럼 `#finale-작품id`를 붙이면 해당 작품의 완성 장면을 바로 볼 수 있습니다.

## 『唐詩畫意』

紫霞 申緯가 엮은 『唐詩畫意』의 五言·六言 절구 126수를 申緯의 차례대로 싣는다. 표지에서 「시작하기」를 누르면 작품 목록이 열리고, 완성한 작품은 ? 자리에 그 풍경이 남는다 (따로 도감 화면은 없다). 『唐詩畫意』에 들지 않은 『唐詩三百首』 13편은 목록 끝의 부록에 있다.

- `docs/唐詩畫意_五六言絶句_목록.md` 확정한 작품 목록 (OCR 교정, 판독이 불완전한 글자는 통행본)
- `src/data/huayi.ts` 申緯의 차례. 아직 만들지 않은 작품은 '준비 중'으로 보인다
- `src/data/poems/huayi8a.ts` 卷八 첫 묶음 15수 (盧照鄰, 王維 輞川集 등, 裴迪 輞川集)
- `src/data/poems/huayi8b.ts` 卷八 둘째 묶음 14수 (儲光羲, 王昌齡, 劉長卿, 孟浩然, 李白)
- `src/data/poems/huayi8c.ts` 卷八 셋째 묶음 21수 (韋應物, 岑參, 皇甫曾, 杜甫, 錢起 江行無題 등, 韓翃, 皇甫冉)
- `src/data/poems/huayi8d.ts` 卷八 넷째 묶음 10수 (柳中庸, 顧況, 耿湋, 戴叔倫, 盧綸, 李端) — 卷八 완료
- `src/data/poems/huayi9a.ts` 卷九 첫 묶음 10수 (暢當, 司空曙, 王建)
- `src/data/poems/huayi9b.ts` 卷九 둘째 묶음 11수 (王建, 劉商, 丘丹, 權德輿 曉·晝·晚, 羊士諤, 裴度, 韓愈)
- `src/render/backgrounds/title.ts` 표지의 봄 꽃나무 풍경
- `src/render/poems/hy_*.ts` 그림. `hy_kit.ts`는 물가 부품(물·부들·연꽃·백로·작은 배 등)
- 王維와 裴迪이 같은 곳을 읊은 작품은 배경을 함께 쓴다 (鹿柴, 北垞)

## 외워 보기

풍경을 완성한 뒤 완성 화면이나 도감에서 「외워 보기」를 누르면, 완성한 풍경을 보며 구절의 빈칸 글자를 3지선다로 맞힙니다.
지금 구절에 해당하는 풍경 조각이 깜박이고, 번역이 함께 나옵니다. 빈칸은 1단계 1개, 2단계 2개, 3단계 3개로 늘어나며,
문제 힌트가 짚은 글자(‘月’ 처럼 따옴표 안)부터 비웁니다. 오답은 같은 시의 다른 구절 글자와, 다른 시에서 같은 자리에 오는 글자입니다.
3단계를 한 번도 틀리지 않으면 誦 도장을 받고 도감에 표시됩니다. 작품 데이터는 따로 손볼 필요가 없습니다 (`src/game/recall.ts`).

## 조작

- 데스크톱: 보기에 커서를 올리면 카드 강조, ‘추가 오브젝트’ 패널, 중앙 풍경의 반투명 임시 배치가 동시에 나타나고, 클릭하면 판정합니다.
- 모바일: 보기를 한 번 누르면 미리보기, ‘선택 확정’을 누르면 판정합니다.
- 키보드: 1·2·3으로 미리보기, Enter로 확정 및 다음 구절.

## 새 시를 추가하는 방법

게임 코드(`components/`, `scene.ts`)는 수정하지 않습니다.

1. `src/render/backgrounds/`에 배경을 만들고(`drawBack`, `drawFront`, `drawDynamic`), `src/render/sprites/`에 보기마다 스프라이트를 하나씩 만든 뒤 `registry.ts`에 등록합니다.
2. `src/data/poems/`에 `Poem` 객체를 만듭니다. 각 보기의 `sprite`에 스프라이트 id를 적고 정답에 `correct: true`를 표시합니다.
3. `src/data/catalog.ts`의 해당 항목을 `playable: true, poem: …`으로 바꿉니다.

시간 변화가 분명한 시는 `scenes`를 여러 개 두면 됩니다. 예를 들어
`[{ background: 'dawn', from: 0, to: 1 }, { background: 'noon', from: 2, to: 3 }, { background: 'night', from: 4, to: 7 }]`
처럼 쓰면 문제 범위에 따라 배경이 바뀌고, 각 장면에는 그 장면에서 얻은 오브젝트만 표시됩니다.
〈登高〉는 원문에 시간의 순차적 변화가 없으므로 단일 장면입니다.

## 픽셀 이미지로 교체하기

지금은 모든 그림을 Canvas 코드로 그립니다. 디자이너가 만든 PNG로 바꾸려면 해당 스프라이트에
`image: { src: '/sprites/bird_circling.png', x: 200, y: 110, frames: 4, fps: 8 }`를 추가하면 됩니다.
이미지가 로드되면 `draw` 대신 이미지(가로로 이어 붙인 프레임 시트)를 씁니다. 좌표는 320×180 캔버스 기준입니다.

## 설계상의 결정

- 오답 보기도 모두 고유한 스프라이트를 가지며, 미리보기 단계에서는 정답을 암시하는 색이나 효과를 쓰지 않습니다.
- 오답 레이어는 미리보기에서만 그려지고 풍경에 저장되지 않습니다. 진행도는 정답을 확정했을 때만 오릅니다.
- 원문과 관계없는 해·달·건축물·동물은 기본 풍경에 넣지 않았습니다. 집(5구 오답)과 다른 인물(6·8구 오답)은 오답 미리보기에만 나타납니다.
- 5구의 행낭은 원문에 없는 상징적 소품이며, 게임 안에서도 해설과 함께 그 점을 밝힙니다.
- 시인별 배지 데이터(`catalog.ts`)는 남아 있지만 지금은 화면에 보이지 않습니다.
- 스프라이트의 `fx` 값으로 장면 전체에 상태를 걸 수 있습니다. 예를 들어 〈旅夜書懷〉 7구의 보기는 배의 움직임을, 〈靜夜思〉 4구의 보기는 시인의 고개 숙임을 바꿉니다.
- 원문은 『唐詩三百首』 통행본을 따랐습니다. 이문(異文)이 있는 곳(〈靜夜思〉, 〈黃鶴樓送孟浩然之廣陵〉 3구)은 작품 해설에 밝혔습니다.
- 구별 번역과 해설은 작업용 초안입니다. `src/data/poems/denggao.ts`에서 바로 고칠 수 있습니다.
